This website uses Norty

Norty is a website view counter modeled after this gif made for a Norton Antivirus product made in the late 1990s that let you show off your antivirus to anyone who went on your website, for some reason.
You can embed Norty into your pages by simply putting "norty.php" on an <img> element. If this instance of Norty allows it, you can identify your website by adding ?id=(word of your choice) to the end of the norty link in your image element. For example: <img src="https://example.com/norty.php?id=mywebsite"> will identify "mywebsite" and count views individually for that website.
There's also a few different GIF templates you can choose from, here's a list:
  1. 88x31
  2. large
  3. largeMac
  4. largeProtectYourself
  5. largeMacProtectYourself
You can use these by putting ?tmp=[name] at the end of your link. Remember that if you're using more than 1 query parameter you have to use & after the first one, for example: "https://example.com/norty.php?tmp=large&id=mywebsite" will show the template large and identify your website as "mywebsite".
That's about what you need to know. If you wanna learn more or check the source code, go to the source code repository in GitHub here.
